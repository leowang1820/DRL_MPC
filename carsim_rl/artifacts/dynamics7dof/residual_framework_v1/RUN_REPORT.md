# 学习补偿 7DOF：第一轮实际运行结果

日期：2026-09-28。未运行新的 CarSim 求解任务，全部基于用户已有真实采集。原物理模型、轮胎拟合和 SAC 控制未修改。

## 实验划分

- 离线训练来源：`open_loop_20260927_233218_823895/capture`，5°名义前轮角、0.5 Hz、无主动驱动/制动，8 s。
- 离线留出来源：`open_loop_20260927_223412_368297/capture`，0.5°、0.3 Hz、带驱动/制动，8 s。
- 拟合样本 1255 条，内部历史保护样本 300 条，其余边界剔除；留出回合标签 1579 条。
- 5 个独立 64×64 MLP，按 50 ms 数据块 bootstrap，GPU 训练 80 轮。没有使用独立验证数据做标准化、梯度更新或选取最佳 epoch。

该回合的驱动制动/速度/加速度范围与训练滑行回合不同。实测状态上的导数诊断样本 100% 触发输入覆盖范围回退；连续积分的状态会与实测状态不同，门控时刻也不完全相同，因此连续结果并非严格逐位等同，但基本回到原模型。

## 按时间回放在线更新

使用初始网络，在原离线留出回合上按顺序接收数据、延迟标签和尝试更新。启用在线更新以后，该回合成为适应数据，不再是适应后网络的独立验证集。

- 共 1579 条可用延迟标签，尝试 7 次候选更新，接受 2 次。
- 误差使用每个标签中心时刻保存的更新前预测计算，没有拿更新后的网络重算过去数据。
- 预测回退比例约 67.1%。

| 导数 | 原模型 RMSE | 顺序学习观察器 RMSE | 单位 |
|---|---:|---:|---|
| dvx/dt | 0.099385 | 0.084742 | m/s² |
| dvy/dt | 0.075839 | 0.095343 | m/s² |
| dr/dt | 0.025163 | 0.026108 | rad/s² |

因此，在线更新机制已经运行，但效果不是全通道改善：横向导数和横摆角加速度总体误差有所增加。历史/近期验证门槛不能保证未来工况不退化，当前模型不应接管控制。

以 `online_replay_guarded/online_report.json` 为最终在线回放报告；该目录的 shadow_ensemble.pt 仅用于后续新工况观察。

## 结论

第一层“物理基线＋残差 ensemble＋分歧＋有门槛的在线观察更新”流程已连通。训练来源回合的连续状态预测有改善；跨工况泛化和在线整体收益尚未通过验收。下一步应补独立工况并扩大训练覆盖，而不是直接进入 Risk 标签刷新或学习控制接管。
