# v2 镜像约束与多工况补偿：实际结果

日期：2026-09-28。基于已有 CarSim 数据离线训练与回放，没有启动新的真实求解。
原物理模型、用户轮胎拟合、SAC 以及原始采集数据均未修改；v1 检查点完整保留。

## 当前结论

直行伪横向/横摆问题已修正，滑行回合整体预测进一步改善。
但驱动制动的横摆角速度仍退化，不能将本轮模型判定为全工况合格，更不能接管控制。
`model_balanced/ensemble.pt` 是供后续旁路试验的候选，不是通过全工况验收的部署模型。
没有进行自动模型替换、Risk 更新或控制接管。

## 改动与实验来源

- 单网络输出采用 h(z)=0.5[g(z)+My g(Mx z)]，精确保持左右反射关系。
- 对称直行时横向、横摆残差为零，仍允许纵向与轮速补偿。
- 前提是平路、均匀附着、左右对称车辆；不适用于分离附着、侧风、横坡等环境。
- 两个训练回合：5°/0.5 Hz 滑行，以及 0.5°/0.3 Hz 驱动制动。
- FIT 2510 条，内部历史保护 600 条；镜像统计不被当成新增独立观测。
- 3°/0.6 Hz 的 1579 条标签仅供开发回归，不参与梯度和标准化。该回合已经影响结构选择，
  不是独立测试。与训练数据约 11.34% 的标签窗口共享确定性启动过程，已在 manifest 明示。
- 第一候选 `model/`：镜像结构、100 轮、全局损失；驱动制动横向误差退化，保留作开发记录。
- 第二候选 `model_balanced/`：镜像结构、按 FIT 回合/通道 RMS 平衡损失、150 轮、CUDA、
  5 个 64×64 成员、seed=42。权重范围 0.5～4；完整训练记录见其 training_report.json。

## 3° 开发对照：全程连续预测

三个版本使用同一采集记录、同一实际轮端输入；只有初始状态取自 CarSim，之后不重置到真值。
共同有效覆盖率 100%，统计范围从 0.1 s 起至采集结束。以下为状态误差，不是导数标签误差。

| 指标 | 原始 7DOF | v1 | v2 平衡候选 |
|---|---:|---:|---:|
| vx RMSE，m/s | 0.212618 | 0.081933 | 0.072621 |
| vy RMSE，m/s | 0.022421 | 0.013090 | 0.005146 |
| r RMSE，rad/s | 0.004010 | 0.003568 | 0.003231 |
| r MAE，rad/s | 0.002381 | 0.002827 | 0.002067 |
| 自由积分平均回退比例 | 不适用 | 18.80% | 1.97% |

报告：[balanced_development_3deg/comparison.html](balanced_development_3deg/comparison.html)。

### 分时段：不能用全程平均掩盖局部退化

| 指标/时段 | 原模型 | v1 | v2 平衡候选 |
|---|---:|---:|---:|
| 转向前 vy RMSE，m/s | 约 0 | 0.009864 | 约 5.6e-16 |
| 转向前 r RMSE，rad/s | 约 0 | 0.005010 | 约 6.4e-16 |
| 转向期间 vy RMSE，m/s | 0.034182 | 0.017950 | 0.005374 |
| 转向期间 r RMSE，rad/s | 0.005959 | 0.004014 | 0.004777 |
| 结束 0.5 s 后 vy RMSE，m/s | 0.001779 | 0.007256 | 0.001317 |
| 结束 0.5 s 后 r RMSE，rad/s | 0.000477 | 0.002215 | 0.000622 |

起始直行的虚假横向运动已消除；转向期间横摆仍好于原模型，但比 v1 差约 19%。
尾段横摆也略差于原模型。因此不能描述成“所有通道、所有时段都改善”。

## 训练回合回归（不能作为泛化证据）

| 回合 | 通道 | 原模型 RMSE | v2 平衡候选 RMSE |
|---|---|---:|---:|
| 5°滑行 | vx，m/s | 0.216640 | 0.061622 |
| 5°滑行 | vy，m/s | 0.033756 | 0.006715 |
| 5°滑行 | r，rad/s | 0.007500 | 0.002203 |
| 驱动制动 | vx，m/s | 0.560832 | 0.188836 |
| 驱动制动 | vy，m/s | 0.012416 | 0.011176 |
| 驱动制动 | r，rad/s | 0.002719 | 0.004289 |

两个训练回合覆盖率均为 100%。驱动制动横摆角速度误差增大约 58%，未通过逐通道验收。
这不是求解器崩溃：其在实测状态上的横摆角加速度 RMSE 从 0.025163 降为 0.008658 rad/s²，
但连续积分的横摆角速度却变差，说明导数拟合改善不能直接推出长时预测改善。
存在累计偏差和状态反馈敏感性的可能，具体贡献尚未逐项分离，不能把原因宣称为已证实。

## 验证与下一步

新增测试覆盖：镜像索引/符号、原物理方程镜像一致性、每个网络成员及回退的镜像一致性、
直行连续积分、Torch/NumPy 一致、梯度传播、旧检查点兼容、在线候选更新、开发数据来源和
分时段指标。所有生成 SVG 均通过 XML 结构检查。

下一步可以用冻结候选在一个新滑行工况上做旁路验证，例如 4°/0.4 Hz；不带 `--learn-online`。
但这不能替代驱动制动问题的修正。后续重点应是驱动制动多步积分误差及状态反馈敏感性，
再考虑多步训练或经过验证的补偿权重设计，而不是仅增加训练轮数后宣称模型已可用于控制。
任何新回合一旦用于调参/结构选择，后续即为开发数据，不再独立。
